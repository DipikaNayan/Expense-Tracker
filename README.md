# 💰 Expense Tracker (Full Stack)

A full-stack expense tracking web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

## 🚀 Features

- 🔐 User Authentication (JWT + bcrypt)
- 👤 Profile Management (View & Edit)
- ➕ Add / Delete Expenses
- 📊 Expense Summary (Income vs Expense)
- 🗂 Category-based tracking
- 📅 Date filtering
- 🔒 Protected Routes

## 🛠 Tech Stack

**Frontend:**

- React.js
- Context API
- Axios

**Backend:**

- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- bcrypt (Password Hashing)

## ⚙️ Installation

### Backend

```
cd Backend
npm install
npm run dev
```

### Frontend

```
cd Frontend
npm install
npm start
```

## 🔐 Environment Variables

Create `.env` file in Backend:

```
PORT=3000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```
